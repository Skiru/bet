# Volleyball - context checklist and sources

Checked 2026-10-26 (`docs/sofa/history/analitycy_2026-10-26/sources_measured_sports.md`).
Access and evidence legends as in `sources-hockey.md`.

**The starting six is not published before the first serve in any league
checked** (PlusLiga / tauronliga.pl, SuperLega, CEV, Data Project federation
sites show it only live). A pre-match read can find injuries and announced
rest, the calendar and the format - nothing more. `UNVERIFIED` is the honest
answer for the six.

## Mandatory - every match, in this order

1. **Is it on, which format** - postponement; best of five with a 15-point
   fifth set; a CEV knockout's golden set (it counts in no market - code
   rule).
2. **Injuries / announced rest** of the opposite, setter or main outside
   hitter (club channels, local press).
3. **Calendar** - a league game wedged between CEV games, an early CEV round
   (rest), the start of the season after national-team summers.

## Checklist

| item | moves | evidence | carries |
|---|---|---|---|
| **Regular opposite / setter / main outside hitter out or rested** | favourite's set handicap and win ↓; sets / total points ↑; 3:0 ↓ | F (direction certain) | WATCH through the leg's variable; NO_BET only when confirmed on two domains and the leg needs the favourite to dominate |
| **CEV double week / early CEV round rest** | as above | E- | WATCH |
| **Import rules** (SuperLega: ≥ 3 Italians on court; Sultanlar Ligi: 3 foreigners on court; PlusLiga: not found) | limits a rotation when an import is out | A (press, not rulebooks) | note |
| **Travel** (CEV away, Russian / Brazilian distances) | away side ↓ | F | note |
| **Dead rubber / seeding settled** | rotation, var ↑ | F | through who plays |
| **Women's vs men's** | set and points distributions differ | F | the code reads only the class's own curve |
| **Fifth set to 15** | total points below a 25-point extrapolation | A | a scope question |
| **Coach change / unpaid wages** | var ↑ | F | note |
| **National-team players returning late** | favourite ↓ early in the season | F | note |
